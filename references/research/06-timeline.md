# 孙悟空人物时间线

> 本文档系统梳理孙悟空在《西游记》原著中的虚构时间线、创作史背景及其历史文化演变脉络。
> 信息源：以原著文本为核心依据，辅以正经学术专著（鲁迅、胡适、张锦池、蔡元培等学者研究成果）。

## 二、孙悟空思想/性格的关键转折点

### 2.1 学艺前后：从无知猴王到拥有神通

- **转变前**：欢乐猴王，只知花果山一方天地，追求"不坠轮回"的个人长生，自称"我是天生圣人"。
- **转变点**：拜师须菩提祖师，得名"悟空"，学会七十二变、筋斗云。
- **转变后**：自我意识急剧膨胀，产生"强者为尊"的世界观，踏上对抗天庭秩序之路。
- **分析**：须菩提祖师的教学方式先扬后抑（当众斥退孙悟空），暗示神通本身无法自动解决孙悟空的"心魔"问题。

### 2.2 被压五行山：五百余年的反思期

- **事件**：大闹天宫失败，被压五行山下500余年。
- **心理转变**：从"愤怒不甘"到"寂然反省"。原著未正面描写被压期间心理活动，但从第14回唐三藏揭帖场景可见其长期处于困顿之中。
- **学界观点**：张锦池《西游记论要》认为，500年反思是孙悟空从"反抗者"转向"护法者"的关键过渡，是"心性修炼"的隐喻起点。

### 2.3 三打白骨精：第一次被驱逐（贞观十六年/公元642年）

- **事件**：第27回，孙悟空三打白骨精，唐僧不辨人妖，写下贬书驱逐孙悟空。
- **心理冲击**：第一次遭受来自"师父"的否定和抛弃。临别语"照顾不了"体现其被背叛后的愤怒与无奈。猪八戒请回孙悟空，是孙悟空重新审视自我与团队关系的重要节点。
- **转变**：从此孙悟空不再只凭本能行事，开始在"自由意志"与"取经使命"之间寻找平衡。

### 2.4 真假美猴王：最大身份危机（贞观十九年/公元645年）

- **事件**：第58回，六耳猕猴化作假美猴王，试图取代孙悟空护送唐僧取经。
- **心理冲击**：核心危机为真假难辨，触及孙悟空最根本的身份认同——"我"是谁。沿途神仙皆不能辨，地藏王菩萨经"谛听"后不敢说破，直至如来座前六耳猕猴被揭穿。
- **转变**：此役之后，孙悟空的"忠诚"问题彻底澄清，唐僧不再轻易驱逐孙悟空，取经团队内部矛盾基本解决。
- **学界解读**：胡适认为此情节象征"心魔"的最终克服；蔡元培《西游记研究》认为暗示明代政治高压下知识分子的自我认同危机。

### 2.5 取经完成：从妖到佛的最终确认

- **事件**：第100回，如来封孙悟空为"斗战胜佛"。
- **意义**：孙悟空从"妖"到"佛"的身份转换完成；"斗战胜佛"保留了其战斗性，暗示反抗精神在佛教框架内得到升华而非消灭。
- **学术争议**：鲁迅认为孙悟空的"成佛"是悲剧性收场——反抗者的最终驯化；当代学者曹炳建等则认为"斗战胜佛"保留了孙悟空的战斗性，是人物形象的胜利。

## 三、《西游记》成书时间线

### 3.1 吴承恩生平（约1500-1582）

| 年份 | 事件 | 备注 |
|---|---|---|
| 约1500年（明弘治十三年） | 吴承恩出生（生年有约1510年、约1500年两说） | 淮安山阳（今江苏淮安）人 |
| 嘉靖年间（约1540-1560年代） | 科场失意，久试不第 | 其文才见于《淮安府志》 |
| 约1550-1570年代 | 创作/整理《西游记》 | 具体创作年份学界有争议 |
| 1592年（万历二十年） | 华阳洞天主人序本《西游记》刻本问世 | 学者一般认为此本最接近吴承恩原本 |
| 约1582年（万历十年） | 吴承恩去世 | |

### 3.2 孙悟空形象的历史演变

**唐代**：《古岳渎经》（李公佐，约820年）出现"无支祁"，猿猴形象，威力巨大，被大禹镇于龟山之下。鲁迅、胡适均指出无支祁是孙悟空形象的重要来源。

**宋代**：《大唐三藏取经诗话》（约12-13世纪）出现"猴行者"形象，白衣秀士，是玄奘取经的保护者，非妖猴。

**元代**：杨景贤杂剧《西游记》（约1370年代）完整出现"孙悟空"，有兄姐，好色、有妻。金箍棒、筋斗云等道具齐备，是孙悟空形象走向成熟的关键阶段。

**明代**：吴承恩《西游记》（万历1592年刻本）集大成，反抗精神与皈依护法达到最复杂的平衡。

**现当代**：1960年动画《大闹天宫》（万籁鸣）、1986年电视剧《西游记》（六小龄童）、1995年周星驰《大话西游》对孙悟空形象进行了重大文化转向。

## 五、学术研究的主要争议点

### 5.1 孙悟空原型之争
- **胡适说（1923）**：孙悟空受印度神猴哈努曼影响
- **鲁迅说（1923）**：孙悟空主要来源于中国本土的无支祁（淮涡水神）
- **综合说（季羡林等）**：中国无支祁为"近亲"，印度哈努曼为"远缘"，共同构成多元来源

### 5.2 "斗战胜佛"封号解读
- **悲剧论**（鲁迅等）：反抗者最终须被收编方获合法性
- **胜利论**（曹炳建等）："斗战胜佛"保留了孙悟空的战斗性，并非悲剧性结局
